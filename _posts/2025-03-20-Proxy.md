### Introduction

For a new student, setting up the proxy at IIT Delhi can be an annoying and time-consuming task. The official guide provided by the [CSC](https://csc.iitd.ac.in/services-network-iitd-proxy.php) is scattered across multiple documents and written in a very formal style, making it hard to follow.

In every lab, it's almost a ritual for senior members to explain proxy setup to newcomers—often doubling as an informal introduction. In many cases, this becomes the first technical discussion a new student has in the lab.

If you're experienced, you might breeze through the official documentation. But for someone new, it can be quite challenging. Many people get stuck wondering, "What does this instruction actually do?"—which, in my opinion, is a great learning exercise.

I've written this blog to simplify the proxy setup process and, more importantly, to explain the purpose of each step. Hopefully, this will save you time and help you understand what's happening behind the scenes.


### Why Do We Need a Proxy Setup?

In the IIT Delhi network, there’s a server sitting between your machine and the internet—this
is called the proxy server. Your machine cannot directly access the internet; instead, it must
send requests to the proxy server, which then fetches the required data from the internet and
relays it back to you.

But why this extra step? Why can’t we just access the internet directly?

The proxy server acts as a secure gateway between the Institute's local network and the public
internet. It plays a crucial role in:

- Monitoring network traffic to maintain security.
- Blocking potentially harmful requests that could compromise the Institute’s network.
- Tracking individual usage for security and policy enforcement.

Proxy setup is the process of configuring your machine to route all internet traffic through
this server. As part of this setup, you’ll need to specify the proxy server address and
authenticate with your credentials to gain internet access.
